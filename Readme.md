# 제주도 초등학교 스쿨존 교통 안전 환경 분석

### 1. 데이터 수집

- 제주 초등학교 스쿨존 교통사고 데이터: 도로교통공단의 교통사고분석시스템(TAAS)에서 어린이 사고 데이터 크롤링
- 제주 어린이 보호구역 교통시설물, 도로 관련 데이터: 공공데이터포털에서 수집
- 제주 초등학교 스쿨존 교통환경 관련 설문조사 데이터: 공공데이터포털에서 수집

### 2. 데이터 전처리

- 스쿨존 교통사고 데이터 전처리
    - 카카오 API를 활용하여 사고 지점을 행정 주소로 변환
- 교통시설물, 도로 관련 데이터 전처리
    - 초등학교의 위경도와 어린이보호구역의 교통시설물, 도로의 위경도 간의 거리가 300m 이하인 경우 스쿨존 교통 환경과 관련이 있다고 판단
- 설문조사 데이터 전처리
    - 자료형 변환: 설문조사 항목 중 순서형 자료를 대상으로 Ordinal Encoding 진행
    - 요인 분석: 순서형 자료에 한정해 15개의 질문 항목을 5개 요인으로 요약, 답변의 요인 계수를 위험도 점수로 변환

### 3. 군집 분석

- K-means 클러스터링을 이용한 초등학교 군집
    - 스쿨존 교통안전 환경이 유사한 초등학교끼리 군집으로 나누어 교통안전 환경의 특징을 살펴보기 위함

### 4. ANOVA

- 초등학교 군집 간 교통안전 환경의 위험 차이가 존재하는지 파악
    - 귀무가설: 군집 간 위험도 점수의 평균 값이 동일하다 vs 대립가설: 군집 간 위험도 점수의 평균 값이 동일하지 않다
    - 사후 검정(Bonferroni t-test)를 통해 차이가 존재하는 군집 파악

### 5. 결론

- 초등학교마다 스쿨존 교통안전 환경에 차이가 존재함을 확인
- 모든 초등학교에 동일한 교통사고 예방 정책을 시행하는 것보다 각 교통안전 환경을 반영한 예방 정책을 시행하는 것이 효과적일 것으로 기대
